# Crediti e risorse di terzi

Questo file raccoglie le principali risorse di terzi incluse nel repository del sito di «PostiPerfetti».

## Font

I font distribuiti nella cartella `fonts/` conservano la propria licenza.

Per i dettagli completi consulta:

```text
fonts/LICENSE
```

## Risorse grafiche

Le risorse grafiche o multimediali provenienti da terzi conservano i rispettivi termini di utilizzo.

Nel repository è presente il credito:

```text
Free Stock Footage by Vecteezy.com
```

come riportato in:

```text
img/LICENCE
```
